# CampusFlow 🎓

A simple web app to help students organize their day. Plan study time, track tasks, and take small steps every day.

## Features

- Welcome dashboard with study and task overview cards
- To-do list where you can add tasks
- Live task counter that updates as you add tasks
- Clean, responsive layout

## Built with

- HTML
- CSS
- JavaScript

## How to run

1. Download or clone this repository:
   ```
   git clone https://github.com/peshbagz-maker/CampusFlow.git
   ```
2. Open `index.html` in your browser.

No installs or build steps needed.
